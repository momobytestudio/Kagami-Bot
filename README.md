- 💰 Global economy system
- 🏦 Wallet & bank system
- 🎁 Daily rewards & streaks
- 💼 Work system
- 🚨 Crime system
- 🥷 Robbery system
- 🎣 Fishing system
- 🎰 Slots
- 🪙 Coinflip
- 🎡 Roulette
- 🙏 Begging

- 🎒 Inventory system

- 👤 User profiles
