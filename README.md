Kagami-Bot

Kagami is a Discord economy bot designed to bring a fun and interactive economy experience to your server.

Built for having fun with friends, Kagami includes a variety of economy, gambling, social, and progression features — with more being developed during the beta.

✨ Features

- 💰 Global economy system
- 🏦 Wallet & bank system
- 🎁 Daily rewards & streaks
- 💼 Work system
- 🚨 Crime system
- 🥷 Robbery system
- 🎣 Fishing system
- 🎰 Slots
- 🪙 Coinflip
- 🎡 Roulette
- 🙏 Begging
- 🛒 Economy shop
- 🎒 Inventory system
- 🏆 Global & server leaderboards
- 👤 User profiles
- 🪙 Credits
- 🛠️ Developer tools
- 🔢 Large-number support with abbreviated values
- 🔐 MongoDB database integration

🧪 Beta

Kagami is currently in beta development.

We are actively:

- Fixing bugs identified by beta testers
- Improving database performance and reliability
- Updating parts of the API
- Improving system stability
- Expanding Kagami's capacity and scalability
- Improving existing features

Some features may change, be temporarily unavailable, or receive major improvements during development.
